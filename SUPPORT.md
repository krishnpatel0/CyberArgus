# Support

Use GitHub Discussions for design and usage questions when enabled. Use a public
issue for reproducible non-sensitive defects and feature proposals. Follow
[SECURITY.md](SECURITY.md) for vulnerabilities; never disclose a vulnerability,
credential, customer record, breach record, or Telegram session in a public issue.

Include the Argus commit/tag, deployment mode, affected module, sanitized logs,
and minimal reproduction steps. Provider-dependent failures should also include
the provider status returned by Argus, without the provider key.
